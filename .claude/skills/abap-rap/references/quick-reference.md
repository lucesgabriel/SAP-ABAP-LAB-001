# ABAP RAP — Quick Reference

> Source: https://github.com/SAP-samples/abap-cheat-sheets/blob/main/36_RAP_Behavior_Definition_Language.md

## BDEF header keywords

| Keyword | Purpose |
|---------|---------|
| `managed` | Framework handles CRUD persistence |
| `unmanaged` | Developer implements all persistence |
| `strict ( 2 )` | Strictest validation — always use in new development |
| `with draft` | Enable draft handling for the whole BO |
| `implementation in class ZBP_MyEntity unique` | Link to behavior pool |

## BDEF entity keywords

| Keyword | Purpose |
|---------|---------|
| `persistent table` | DDIC table for active data (managed only) |
| `draft table` | Table for draft data |
| `etag master FieldName` | Field for optimistic locking |
| `lock master` | Defines lock master entity |
| `field ( readonly )` | Fields the user cannot change |
| `field ( numbering : managed, readonly )` | UUID auto-generated by framework |

## Standard operations

```abap
create;               " Allow CREATE
update;               " Allow UPDATE
delete;               " Allow DELETE
```

## Draft actions (copy-paste for any draft-enabled BO)

```abap
draft action Edit;
draft action Activate optimized;
draft action Discard;
draft action Resume;
```

## Validation vs Determination

| | Validation | Determination |
|-|-----------|--------------|
| Purpose | Check data, raise errors | Calculate/set fields |
| Modifies data? | ❌ No | ✅ Yes |
| Trigger | `on save` | `on modify` or `on save` |
| Stops save? | ✅ Yes (on error) | ❌ No |

## Handler method signatures

```abap
" Validation
METHODS myValidation FOR VALIDATE ON SAVE
  IMPORTING keys FOR Entity~myValidation.

" Determination
METHODS myDetermination FOR DETERMINE ON MODIFY
  IMPORTING keys FOR Entity~myDetermination.

" Action with result
METHODS myAction FOR MODIFY
  IMPORTING keys FOR ACTION Entity~myAction RESULT result.

" Read handler (unmanaged)
METHODS readEntity FOR READ
  IMPORTING keys FOR Entity RESULT result.
```

## READ ENTITIES pattern

```abap
READ ENTITIES OF ZI_Root IN LOCAL MODE
  ENTITY MyEntity
    FIELDS ( Field1 Field2 )
    WITH CORRESPONDING #( keys )
  RESULT DATA(lt_data)
  FAILED failed.
```

## MODIFY ENTITIES pattern (inside handler — always IN LOCAL MODE)

```abap
MODIFY ENTITIES OF ZI_Root IN LOCAL MODE
  ENTITY MyEntity
    UPDATE FIELDS ( Status )
    WITH VALUE #( FOR key IN keys (
      %tky   = key-%tky
      Status = 'X' ) )
  FAILED   failed
  REPORTED reported.
```

## Error reporting pattern

```abap
APPEND VALUE #(
  %tky        = ls_data-%tky
  %state_area = 'MY_VALIDATION'
  %msg        = new_message_with_text(
    severity = if_abap_behv_message=>severity-error
    text     = 'My error message' )
  %element-MyField = if_abap_behv=>mk-on )  " Highlight field
  TO reported-myentity.

APPEND VALUE #( %tky = ls_data-%tky ) TO failed-myentity.
```
