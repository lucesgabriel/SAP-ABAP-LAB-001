# Ejercicios

Copia [templates/exercise.md](../templates/exercise.md) aquí como `abap-001-tema.md`. Agrupa por tema cuando crezca el catálogo: `fundamentals/`, `oo/`, `cds/`, `rap/` o `quality/`, creando solo carpetas que tengan ejercicios.

Cada ejercicio describe una habilidad y enlaza su proyecto y evidencia. No dupliques el código. Para navegar y buscar ejercicios puedes usar `rg --files learning/exercises` desde la raíz.
