# Aprendizaje continuo

Empieza con la [ruta sugerida](roadmap.md). El aprendizaje se demuestra con ejercicios y evidencia; completar una lectura o crear una carpeta no acredita dominio.

| Lugar | Qué registrar |
| --- | --- |
| [exercises/](exercises/README.md) | Objetivos de práctica, criterios y enlaces al proyecto que los implementa. |
| [sessions/](sessions/README.md) | Lo observado en una sesión, dudas y siguiente paso. |
| [templates/](templates/README.md) | Formatos para ejercicios y sesiones. |
| [lessons.md](lessons.md) | Solo lecciones comprobadas y reutilizables, con evidencia. |
| [decisions.md](decisions.md) | Decisiones vigentes que afectan al laboratorio. |
| [patterns.md](patterns.md) | Patrones ABAP aprobados; no guardar propuestas como aprobadas. |
| [backlog.md](backlog.md) | Deuda y mejoras globales. |

## Ciclo

Elige una habilidad → define un ejercicio → trabaja en un proyecto → verifica → registra la sesión → promueve una lección comprobada → aplica la lección en el siguiente ejercicio.

Mantén el código en `projects/<id>/src/` y enlázalo desde el ejercicio, sin copiarlo. Las decisiones y pendientes exclusivos de ese proyecto permanecen en sus documentos. Antes de añadir una lección, busca si ya existe; amplía o reemplaza la anterior si hay nueva evidencia. Las hipótesis siguen en sesiones o backlog.
