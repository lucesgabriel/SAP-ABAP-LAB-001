# Sesiones de aprendizaje

Copia [templates/session.md](../templates/session.md) como `YYYY-MM-DD-tema.md`. Si crece el historial, agrupa por año y mes. Cada nota debe dejar un siguiente paso concreto y distinguir observaciones de hipótesis.

Para trabajo de un solo proyecto, usa preferentemente su `docs/journal.md` y enlázalo desde el ejercicio; no mantengas dos bitácoras de la misma sesión.
