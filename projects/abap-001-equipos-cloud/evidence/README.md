# Evidencias revisadas

Guarda resúmenes pequeños en `YYYY-MM-DD-tema.md`: fecha, herramienta/acción, objetos, resultado esperado, resultado observado y conclusión. Enlaza cada resultado desde el backlog o ficha de cierre.

Revisa manualmente cada archivo antes de versionarlo. No guardar credenciales, cabeceras de autenticación, cookies, respuestas completas con datos sensibles ni exportaciones masivas. Las salidas locales regenerables y sanitizadas van a `artifacts/<id-del-proyecto>/`, que está ignorado por Git; incluye aquí un resumen durable si ese archivo fundamenta una entrega.

Una captura o un write exitoso no demuestran por sí solos activación o pruebas satisfactorias.
