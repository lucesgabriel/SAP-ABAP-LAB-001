# Código ABAP

Guarda aquí código propuesto o exportado. Añade `classes/`, `reports/`, `cds/` o `rap/` solo cuando corresponda. Conserva la serialización de abapGit si se utiliza y documenta su raíz real; esta plantilla no configura abapGit.

Para cada importación o lectura, registra fecha, objeto, versión activa/inactiva, paquete y herramienta de origen en el diario. Distingue una propuesta local de una versión activada y releída en SAP. Incluye las pruebas ABAP Unit junto con la clase cuando corresponda.

El código actual leído en SAP prevalece sobre estas copias.
