# Standards

Convenciones transversales del laboratorio. Se aplican a proyectos y casos; los casos de práctica evalúan su cumplimiento en la rúbrica.

| Documento | Uso |
|---|---|
| [naming-conventions.md](naming-conventions.md) | Nombres de paquetes, clases, CDS, RAP, tablas, métodos, tests y archivos locales. |
| [technology-decision-matrix.md](technology-decision-matrix.md) | Qué tecnología ABAP elegir según el requerimiento (report, clase, CDS, RAP, AMDP, BAdI, OData) y nivel clean core. |

Los cambios a estos documentos se registran en el changelog de cada archivo y, si nacen de un proyecto, se citan como decisión `D-NNN`.
