# Claude Code — SAP ABAP LAB 001

Lee y aplica íntegramente `AGENTS.md` antes de trabajar.

## Plugins disponibles
- `clean-abap@claude-abap-skills`
- `abap-cloud-rap@claude-abap-skills`
- `arc-1@arc-1`

## Inicio recomendado
1. Lee `config/system.yaml`, `AGENTS.md` y `learning/decisions.md`.
2. Confirma la conexión MCP y descubre las herramientas activas.
3. Para inspección usa ARC-1; para cambios sigue el flujo obligatorio de `AGENTS.md`.
4. Invoca el skill especializado que corresponda.

## Regla de conexión
No copies credenciales SAP a este repositorio ni a la configuración del proyecto. La autenticación pertenece al almacén privado del cliente MCP.
