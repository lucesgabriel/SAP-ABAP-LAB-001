# Salidas locales

Esta carpeta conserva las colecciones y salidas existentes (`bruno/`, `postman/`, `manual-pages/` y `manual-text.json`). Su contenido está excluido de Git, salvo esta guía.

Para nuevas salidas usa `artifacts/<id-del-proyecto>/<tipo>/`, por ejemplo una subcarpeta `reports/` o `exports/`. Guarda solo material sanitizado y regenerable. No almacenar secretos, aunque esté ignorado por Git.

Las evidencias pequeñas y revisadas que respaldan una entrega se guardan en `projects/<id>/evidence/`, con fecha, procedencia y resultado. No confiar en una ruta ignorada como única evidencia durable.

Las colecciones existentes no se ejecutaron ni se trasladaron durante la organización de carpetas.
